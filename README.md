# Autopilot Live Demo

Interactive browser simulation of **Autopilot + Mandate**: AI agents that launch and run a paid SMS quiz service, with a safety layer that only lets them charge within limits people approved by one-time code.

Open `index.html` in any browser, or visit the GitHub Pages link. Press **Start guided demo** and then **Next step**.

The agents are scripted for the demo; no real SMS or money is involved.
